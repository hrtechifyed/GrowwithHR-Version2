# GrowWithHR v0.20.0 — M5 Compliance Workspace Beta

Status: **released**  
Release date: **27 July 2026**  
Route: `/m5-compliance-workspace.html`  
Public production route: unchanged  
Persistence: browser-local only

## Purpose

M5 turns advisory actions into a lightweight execution workspace without changing the approved privacy posture. It helps a founder record owners, target dates, status history, evidence placeholders and calendar entries after reading the advisory report.

## Released scope

- browser-local task register;
- task owners and descriptions;
- status history using not started, in progress, blocked and complete;
- due dates with an explicit source state;
- local evidence placeholders that do not upload files;
- browser-local calendar entries;
- JSON backup export and import;
- strict nested backup validation before import;
- isolated workspace reset;
- in-memory fallback when browser storage is unavailable;
- no server call, account, authentication, database or cloud persistence.

## Protected boundaries

- `/analyze-company.html` remains the stable public assessment route;
- private v3 and M4 routes remain unchanged;
- existing assessment, report, lead, PDF and delivery storage keys are not modified;
- workspace data uses only `growwithhr-compliance-workspace-v1`;
- resetting the workspace does not delete assessment or report data;
- imported backups are schema-checked before replacing local workspace state;
- evidence records are placeholders only and do not prove compliance.

## Exit evidence

- task creation and status history are deterministic and covered by contract tests;
- every due date displays its source state;
- export/import round-trip preserves the workspace;
- malformed nested task, evidence, calendar and audit records are rejected;
- reset affects only the M5 key;
- static checks confirm that the workspace UI performs no network request;
- Playwright covers task, evidence and calendar creation, browser-local persistence, isolated reset and storage-unavailable fallback;
- the complete maintained test chain includes the M5 contract checks;
- the canonical version is `0.20.0`.

Revert the coordinated `v0.20.0` release commit or remove the private M5 route and its two JavaScript files. Existing report, assessment and delivery data require no migration or cleanup. The workspace key can be left unread or removed independently by the user.
