# GrowWithHR v0.21.0 — M6 Evidence and Persistence Contract Foundation

Status: **contract foundation only; runtime implementation not approved**  
Canonical application version: **0.20.0**  
Runtime impact: **none**  
Layout impact: **none**

## Purpose

This change establishes reviewable, versioned contracts and negative tests for the planned v0.21 Evidence and Persistence Beta. It does not add authentication, a database, server persistence, file upload, cross-device resume or any user-interface change.

## Added contracts

The schema package defines:

- organisation profile;
- workspace task and status history;
- evidence metadata and lifecycle state;
- consent record;
- audit event;
- export package;
- deletion completion receipt;
- encrypted backup manifest;
- local-to-remote migration receipt.

Every record carries tenant and organisation boundaries, timestamps and source provenance. Unknown properties are rejected.

## Safety assertions

The maintained contract test confirms:

- the canonical package remains `0.20.0`;
- runtime persistence is disabled in the contract fixture;
- evidence file content cannot be represented as stored;
- local migration must preserve the source;
- backup manifests must record encryption;
- deletion receipts must disclose backup expiry;
- withdrawn consent requires a withdrawal timestamp;
- cross-tenant fixture mixing is rejected by the contract test;
- unapproved fields fail strict schema validation.
