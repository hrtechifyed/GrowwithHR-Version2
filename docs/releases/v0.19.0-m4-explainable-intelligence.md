## Purpose

M4 converts the validated M2 traceability and M3 Compliance Story contracts into separate, explainable intelligence dimensions without producing a blended compliance score.

The release provides profile completeness, applicability certainty, evidence coverage, ranked information-gain questions and a reproducible decision trace.

## Safety and compatibility

- No blended health, maturity or compliance score is produced.
- Applicability, completeness and evidence remain separate.
- The model is deterministic for the same input.
- No cloud persistence, authentication or evidence upload is added.
- The result is not legal certification.
- `/analyze-company.html` remains the stable public route.
- Private v3 and M4 routes remain private.
- `complianceDnaV3` remains disabled by default.
- Protected browser-storage, report, PDF, email and delivery contracts remain compatible.

## Acceptance evidence

The release maintains three separate governed metrics, deterministic output, ranked targeted questions, a minimum five-step trace, JSON Schema 2020-12 validation, founder-facing report integration and one controlled Light/Dark PDF structure.

The final release validation rerun is executed after all generated version surfaces and maintained assertions are synchronized on the release branch.
